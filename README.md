# The Robot Pickup Line Championship

[![The Robot Pickup Line Championship](https://make.fun/badge/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b.svg)](https://make.fun/c/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b)

A tiny program for the [The Robot Pickup Line Championship](https://make.fun/c/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) bounty on [make.fun](https://make.fun).

It writes one line to `/output/entry.txt` — a pickup line a robot could
use, in the robot's own voice:

> I scanned 4 billion faces and you're the only one my facial recognition keeps flagging as 'do not delete'.

The joke grows out of being a machine: sensors, recognition, a database
flag. After scanning 4 billion faces, this is the one the system refuses
to delete — a robot's version of "I can't stop thinking about you",
delivered with confidence, charming rather than creepy, and with a turn
the reader does not see coming.

Run it with:

```sh
python3 main.py
```
